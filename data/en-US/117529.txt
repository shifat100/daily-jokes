GHOUGHPHTHEEIGHTTEAU
If GH stands for P as in Hiccough. 

If OUGH stands for O in Dough. 

If PHTH stands for T as in Phthisis. 

If EIGH stands for A as in Neighbor. 

If TTE stands for T as in Gazette. 

If EAU stands for O is in Plateau. 

Then we have GHOUGHPHTHEEIGHTTEAU. 

We now know the correct way to spell POTATO.
